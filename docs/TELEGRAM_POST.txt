# Текст поста для текущей тестовой сборки: одна строка = один пункт. Обновлять при каждой публикации.
Лечебница: экспериментальный фикс скриншотов для выбранных 64-битных приложений на Android 15–17; добавлен поиск.
Скриншоты: учтена защита графических слоёв; аппаратно защищённое видео может оставаться чёрным.
Zygisk: списки ART и LSPosed раскрываются после первых трёх записей.
Твики ядра: вместо 1 и 0 для соответствующих значений показаны «вкл.» и «выкл.».
Диагностика: кнопки после загрузки, непрозрачное меню логов и уведомления в цветах ASB.
Логи: повторно используется asbdiag текущей сборки с проверкой отпечатка; улучшена устойчивость сбора.
Smart: Вечный лог записывает состояние I/O-планировщиков и фаз работы с учётом устройства.
Action → Аудио: доступные параметры Bluetooth и аудиовыхода без подмены формата исходного трека.
Стабильность: надёжнее восстановление настроек сна и обработка ответов интерфейса.
