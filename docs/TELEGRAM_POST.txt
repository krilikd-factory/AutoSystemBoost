# Текст поста для текущей тестовой сборки: одна строка = один пункт. Обновлять при каждой публикации.
Скриншоты: учтены окна воспроизведения Android 17; флаги защиты слоёв снимаются точно по маске.
Скриншоты: статус честнее — «выбор опубликован» не значит «перехват работает»; защищённое видео может остаться чёрным.
Smart: фоновая загрузка по Wi-Fi, как и мобильная, больше не принимается за простой.
Вечный лог: советы обновляются по свежему логу, применённое не предлагается снова; добавлен совет про LTE при выключенном экране.
Zygisk: служебные процессы приложений (…_zygote) больше не считаются отдельными приложениями.
Zygisk: при выключенных классах запуска не обещается «быстрый/медленный старт».
asbdiag: сработавшая защита DSP помечается HELD, а не FAIL; точнее описан маршрут DSP.
Устройство: намеренно очищенные свойства показаны как совпадающие.
Стабильность: надёжнее установка перехвата скриншотов при сбое JNI.
