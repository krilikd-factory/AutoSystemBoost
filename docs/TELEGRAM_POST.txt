# Строки с # не публикуются. Обновляется вместе с каждой сборкой.
Рядом с SMART снова видно реальное значение ядра (kyber, 1, 0…); пилюли, повторяющие выбранную кнопку, убраны — остаётся только то, чего не видно в самом переключателе.
«Отправить логи в Bugs»: архив теперь передаётся так же, как при ручном выборе файла через системный проводник — должно убрать «Вложение не поддерживается».
Твики, привязанные к профилю, честно пишут, когда не действуют: например «Заводской потолок CPU: Профиль „Производительность“» в профиле Smart — «не действует».
Поиск в настройках находит инструменты Лечебницы: «Activity», «Service», SOTER, очистку — с переходом прямо к карточке.
Окно «Тренд» больше не противоречит само себе: график, пунктир и скорость считаются по одному окну, сигнал governor показан отдельно.
Выпадающие списки — ровный фон без двухцветной полосы, выбранный пункт в цвете категории; убрано длинное пояснение под расходом батареи.
