# Текст поста в Telegram для текущей тестовой сборки: одна строка = один пункт.
WebUI: названия твиков аккуратнее переносятся рядом со стрелкой пояснения, а показатели ядра сохраняют своё место при проверке.
Ядро: правила пробуждений с точными именами сохраняются при обновлении модуля; добавлена резервная копия списков.
Уведомления: сохранены предыдущие исправления совместимости и проверки разрешений для приложений, включая Mail.ru.
Отправка логов: сохранены проверки архива и возможность вручную отправить файл из Download, если Telegram не принял вложение.
Обновляйтесь поверх и перезагрузите телефон. Вечный лог после обновления должен автоматически начать новый период; если не запустился — включите сбор заново. Неотправленные прежние логи сохраните и отправьте в Bugs.
